# Workshop priorities

User-selected areas for upcoming work:

- Project browser for saved sheets.
- Image preparation tools.
- Further PNG tracing refinements.
- More arrangement tools.
- Richer decal editing.
- Multi-decal car preview, driven by the sheet selection.

The selection and preview foundation is implemented in 0.2.4: drag-box selection, modifier-click selection, moving selections together, and independently placing selected decals on the car.

Version 0.2.5 implements the faster-arrangement priority: grids of copies with exact gaps and an A4 preview; all six edge/centre alignments; equal horizontal/vertical gaps; mirroring; and moving selections to existing or new pages.

Version 0.2.6 implements the project browser, saved-sheet thumbnails, recent ordering and search, automatic preservation before switching, saved project history and workspace sheet recovery into independent copies.

Version 0.2.7 implements image preparation: drag/exact cropping, edge-connected colour removal with a picker and tolerance, transparent-edge trimming, transparent/light/dark previews, retained originals and restoration, with printed scale and placement preserved.

Version 0.2.8 implements trace colour replacement, individual shape removal, local refinement undo/redo, linked comparison zoom/scroll, preserving saved refinements on reopening and clear raster/vector/traced/mixed artwork badges.

Version 0.2.9 implements editing inside groups (including nested groups, local undo/redo, locked elements and atomic apply) and editable racing-number templates with matching pairs.

Version 0.2.10 implements editable curved text, including group editing and native PDF text, and adjustable silhouette outlines for imported artwork with retained sources, vector borders and removal.

Version 0.2.11 resolves all eight full-review findings and adds validation at the workspace storage boundary, safe collection limits, accurate nested group bounds and a dedicated desktop regression suite.

All priorities in this workshop roadmap are implemented.

Online sharing and Livery connections remain later possibilities. Local editable sheet and decal-pack sharing already work.
